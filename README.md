# Documentação do SeaPass

## 1. Tecnologias Utilizadas
O SeaPass foi desenvolvido utilizando HTML, CSS e JavaScript.  
A aplicação possui estrutura modular, com arquivos individuais por página e dois arquivos globais:
- CSS para tema escuro
- JavaScript para ativação do modo noturno

## 2. Estrutura das Telas

### 2.1 Tela de Login e Cadastro
Permite acessar ou criar conta, com campos de e-mail e senha e navegação para registro.

### 2.2 Tela Inicial (Home)
Página principal após login, com navegação para pesquisa e visualização de hotéis.

### 2.3 Tela de Detalhes do Hotel
Exibe imagem em destaque, nome, endereço, comodidades e opção de avançar para reserva.

### 2.4 Tela de Reserva
Mostra avaliações e oferece três opções de quarto (básico, intermediário e superior), com seleção de datas e hóspedes.

### 2.5 Tela de Reserva Concluída
Exibe resumo e confirmação da reserva realizada.

### 2.6 Tela de Configurações
Permite alternar tema claro/escuro e ajustar tamanho da fonte.

## 3. Melhorias Implementadas na Nova Versão

### 3.1 Reestruturação da Interface
Interface reorganizada com navegação mais intuitiva.

### 3.2 Inclusão da Tela de Detalhes do Hotel
Nova página com informações completas e imagens.

### 3.3 Novo Sistema de Reserva
Processo dividido em etapas com maior clareza.

### 3.4 Tela de Confirmação Estruturada
Confirmação final mais clara para o usuário.

### 3.5 Implementação do Modo Noturno
